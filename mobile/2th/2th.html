HTML

HTML은 웹페이지를 만들기 위해 사용하는 마크업 언어입니다. HTML은 HyperText Markup Language의 약자로, 웹페이지의 구조와 내용을 정의하는 데 사용됩니다. HTML 문서는 다양한 요소와 태그를 사용하여 텍스트, 이미지, 링크, 비디오 등 다양한 콘텐츠를 표시할 수 있습니다. HTML은 웹 브라우저에서 해석되어 사용자에게 시각적으로 표시됩니다.

XML

XML은 Extensible Markup Language의 약자로, 데이터를 저장하고 전송하기 위한 마크업 언어입니다. XML은 HTML과 유사하지만, HTML이 웹페이지의 구조를 정의하는 데 사용되는 반면, XML은 데이터의 구조를 정의하는 데 사용됩니다.
